How do I export from Quicken Classic?

In Quicken Classic for Windows, open File → File Export → QIF file. Choose an account and the full date range you want to move. Include Transactions, Account List, and Category List where available. Save the export locally, then choose it here.

Keep your original Quicken backup. A .QDF database or .QXF transfer file is not a QIF export and cannot be opened here. For an unnamed, single-account export, enter its name above.

This preview normalizes supported banking, credit-card, cash, asset, and liability transaction records. Investment and other unsupported records are retained in the archive and reported separately. Attachments, budgets, schedules, settings, and complete investment tax lots are outside this transaction migration.
